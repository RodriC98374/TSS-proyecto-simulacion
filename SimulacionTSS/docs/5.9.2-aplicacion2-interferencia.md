# 5.9.2. Aplicación 2 — Interferencia eje-cojinete

Paquete `tss.modelo.interferencia`, 4 clases. Estima la probabilidad de que el
diámetro del cojinete resulte menor que el de la flecha (holgura negativa).

## Resumen de clases

| Clase | Rol |
|---|---|
| `ParametrosInterferencia` | Medias/desviaciones de cojinete y flecha, y la probabilidad de referencia. |
| `SimuladorInterferencia` | Motor: genera ensambles y estima la probabilidad de interferencia. |
| `EnsambleSimulado` | Un ensamble (cojinete, flecha, holgura, veredicto). |
| `ResultadoInterferencia` | Resultado agregado: probabilidad, convergencia, histograma. |

---

## `ParametrosInterferencia`

```java
public record ParametrosInterferencia(
        double mediaCojinete, double desviacionCojinete,
        double mediaFlecha, double desviacionFlecha) {

    public static final double PROBABILIDAD_REFERENCIA = 0.34458;
    public static final double Z_95 = 1.96;
    public static final double ERROR_OBJETIVO = 0.01;

    public double mediaHolgura() {
        return mediaCojinete - mediaFlecha;
    }

    public double desviacionHolgura() {
        return Math.sqrt(desviacionCojinete * desviacionCojinete
                + desviacionFlecha * desviacionFlecha);
    }
}
```

`mediaHolgura()` y `desviacionHolgura()` combinan las dos normales en la
distribución de la holgura `D = X1 − X2`, usada para ubicar el histograma.

## `SimuladorInterferencia`

```java
public ResultadoInterferencia simular(int ensambles, ProgresoSimulacion.Monitor monitor) {
    for (int i = 1; i <= ensambles; i++) {
        MuestraNormal cojinete = generador.generarNormalDetallada(
                parametros.mediaCojinete(), parametros.desviacionCojinete());
        MuestraNormal flecha = generador.generarNormalDetallada(
                parametros.mediaFlecha(), parametros.desviacionFlecha());
        double holgura = cojinete.valor() - flecha.valor();
        boolean interfiere = holgura < 0.0;

        if (interfiere) conInterferencia++;
        conteos[claseDe(holgura, bordes)]++;      // histograma de la holgura
        marcasX.add(i);                            // serie de convergencia
        marcasY.add((double) conInterferencia / i);
    }
    double probabilidad = (double) conInterferencia / hechos;
    ...
}
```

Cada ensamble genera los dos diámetros por el teorema del límite central
(12 uniformes cada uno), calcula la holgura como su diferencia y la marca
como interferencia cuando es negativa. En paralelo acumula el histograma de
la holgura y la serie de convergencia de la probabilidad estimada.

Segundo método clave: tamaño de muestra necesario para un error dado.

```java
public static int calcularTamanioMuestra(double p, double error, double z) {
    double n = (z * z * p * (1.0 - p)) / (error * error);
    return (int) Math.ceil(n);
}
```

Aplica `n ≥ z²·p·(1−p)/e²` y redondea hacia arriba. Con `p = 0,34458`,
`error = 0,01` y `z = 1,96` (95 %) devuelve **8.677** ensambles.

## `EnsambleSimulado` y `ResultadoInterferencia`

```java
public record EnsambleSimulado(
        int numero, MuestraNormal cojinete, MuestraNormal flecha,
        double holgura, boolean interferencia) { ... }

public record ResultadoInterferencia(
        ParametrosInterferencia parametros, int ensambles, int conInterferencia,
        double probabilidad, double referencia, double diferenciaAbsoluta,
        double mediaCojineteGenerada, double mediaFlechaGenerada,
        int tamanioMuestraRequerido, List<EnsambleSimulado> traza,
        int[] convergenciaEnsambles, double[] convergenciaProbabilidad,
        double[] bordesHolgura, int[] conteosHolgura) { }
```

`EnsambleSimulado` es la fila de la traza detallada (un ensamble con sus dos
piezas y el veredicto). `ResultadoInterferencia` es el resumen final:
probabilidad estimada vs. la referencia analítica, la serie de convergencia
y el histograma de la holgura.

## Resultado esperado

p ≈ 0,3446 (referencia analítica 0,34458) y n = 8.677 ensambles requeridos
para un error del 1 % con 95 % de confianza.
