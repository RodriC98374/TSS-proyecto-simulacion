# 5.9.4. Aplicación 4 — Reemplazo de componentes

Paquete `tss.modelo.reemplazo`, 6 clases. Simulación orientada a eventos de
un equipo de cuatro componentes; compara reemplazar solo el que falla contra
reemplazar los cuatro juntos.

## Resumen de clases

| Clase | Rol |
|---|---|
| `ParametrosReemplazo` | Vida normal, horizonte y costos de componente/paro. |
| `PoliticaReemplazo` | Enum: reemplazo individual (A) vs. total (B). |
| `SimuladorReemplazo` | Motor: avanza de falla en falla y aplica la política. |
| `EventoFalla` | Traza de una intervención (instante, pieza, costo acumulado). |
| `ResultadoCorridaReemplazo` | Totales de una corrida sobre todo el horizonte. |
| `ResumenReemplazo` | Promedios de muchas corridas para una política. |

---

## `ParametrosReemplazo` y `PoliticaReemplazo`

```java
public record ParametrosReemplazo(
        int componentes, double horizonte, double mediaVida, double desviacionVida,
        double costoComponente, double costoHoraParo,
        double horasParoIndividual, double horasParoTotal) {

    public static ParametrosReemplazo porDefecto() {
        return new ParametrosReemplazo(4, 20000.0, 600.0, 100.0, 200.0, 100.0, 1.0, 2.0);
    }
}

public enum PoliticaReemplazo {
    INDIVIDUAL("Política A", "Reemplazar solo el componente que falla"),
    TOTAL("Política B", "Reemplazar los cuatro componentes en cada falla");
}
```

## `SimuladorReemplazo`

Algoritmo orientado a eventos: cada iteración salta al componente cuya falla
está más próxima.

```java
public ResultadoCorridaReemplazo simularCorrida(PoliticaReemplazo politica) {
    while (true) {
        int m = indiceDeMenor(falla);              // componente con falla mas proxima
        if (falla[m] > parametros.horizonte()) break;

        double reloj = falla[m];
        if (politica == PoliticaReemplazo.INDIVIDUAL) {
            consumidos += 1;
            horasParo += parametros.horasParoIndividual();
            vida = reemplazarIndividual(falla, m, reloj);
        } else {
            consumidos += piezas;
            horasParo += parametros.horasParoTotal();
            vida = reemplazarTodos(falla, reloj);
        }
        traza.add(new EventoFalla(intervenciones, reloj, m + 1, vida, ...));
    }
    return new ResultadoCorridaReemplazo(politica, intervenciones, consumidos, horasParo,
            costoComponentes, costoParo, costoComponentes + costoParo, traza);
}
```

Política A — reemplazo individual: desplaza primero la hora de paro a los
cuatro relojes de falla (durante la desconexión nadie envejece), y recién
después reprograma solo la pieza sustituida.

```java
private double reemplazarIndividual(double[] falla, int m, double reloj) {
    double paro = parametros.horasParoIndividual();
    for (int i = 0; i < falla.length; i++) {
        falla[i] += paro;
    }
    double vida = generarVida();
    falla[m] = reloj + paro + vida;
    return vida;
}
```

Política B — reemplazo total: las cuatro piezas salen nuevas tras la
desconexión.

```java
private double reemplazarTodos(double[] falla, double reloj) {
    double paro = parametros.horasParoTotal();
    for (int i = 0; i < falla.length; i++) {
        falla[i] = reloj + paro + generarVida();
    }
    return primera;
}
```

Vida de un componente, normal por el teorema del límite central y acotada a
no negativos:

```java
private double generarVida() {
    double vida = generador.normalPorTeoremaLimiteCentral(
            parametros.mediaVida(), parametros.desviacionVida());
    return Math.max(vida, 0.0);
}
```

## `EventoFalla`, `ResultadoCorridaReemplazo`, `ResumenReemplazo`

```java
public record EventoFalla(
        int numero, double instante, int componente, double vidaGenerada,
        double horasParo, int componentesAcumulados, double costoAcumulado) { }

public record ResumenReemplazo(
        PoliticaReemplazo politica, int corridas, double intervenciones,
        double componentesConsumidos, double horasParo, double costoComponentes,
        double costoParo, double costoTotal, double costoPorHora) { }
```

`EventoFalla` es la fila de la traza (una intervención). `ResumenReemplazo`
es la fila de la tabla comparativa: promedios de muchas corridas para una
política.

## Resultado esperado

Gana la **Política A** (reemplazo individual), con un costo total promedio
de ≈ $39.157 por 20.000 horas de operación.
