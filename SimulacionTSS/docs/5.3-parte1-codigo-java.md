# 5.3. Parte 1 — Código en Java

La Parte 1 (ejercicios 1 y 2, método de rechazo de Coss Bu) se implementa en el
paquete `tss.modelo.rechazo` con 5 clases. Un solo simulador atiende ambos
ejercicios: lo único que cambia es la densidad que recibe.

## Resumen de clases

| Clase | Rol |
|---|---|
| `Tramo` | Un tramo lineal (o constante) de la densidad: `f(x) = pendiente·x + intercepto`. |
| `DensidadPorTramos` | Densidad completa por partes; arma los dos ejercicios y evalúa `f(x)`. |
| `SimuladorRechazo` | Motor del algoritmo: genera `R1`, `R2` y decide aceptar/rechazar. |
| `IteracionRechazo` | Una fila de la traza (prueba de escritorio): `R1, R2, x, f(x), M, decisión`. |
| `ResultadoRechazo` | Resultado agregado de la corrida: aceptados, tasa, histograma. |

---

## `Tramo`

Record que representa un tramo de la densidad. Con `pendiente = 0` es un
escalón; con `pendiente ≠ 0` es una rampa.

```java
public record Tramo(double inicio, double fin, double pendiente, double intercepto, String etiqueta) {

    public double evaluar(double x) {
        return pendiente * x + intercepto;
    }

    public double maximo() {
        return Math.max(evaluar(inicio), evaluar(fin));
    }
}
```

`evaluar(x)` es el único método relevante: evalúa la recta del tramo en `x`.
`maximo()` da el mayor valor del tramo (sirve para construir la cota `M`).

## `DensidadPorTramos`

Junta los tramos en una sola densidad y expone las dos fábricas que son,
literalmente, el enunciado de cada ejercicio.

```java
/** Ejercicio 1: f(x) = 3/4 en [0,1] y f(x) = 1/4 en (1,2]. */
public static DensidadPorTramos escalonada() {
    return new DensidadPorTramos("Densidad escalonada", List.of(
            Tramo.constante(0.0, 1.0, 3.0 / 4.0, "3/4"),
            Tramo.constante(1.0, 2.0, 1.0 / 4.0, "1/4")));
}

/** Ejercicio 2: f(x) = 3/4 en [0,1] y rampa -(9/8)x + 15/8 en (1, 5/3]. */
public static DensidadPorTramos escalonConRampa() {
    return new DensidadPorTramos("Escalon y rampa descendente", List.of(
            Tramo.constante(0.0, 1.0, 3.0 / 4.0, "3/4"),
            Tramo.lineal(1.0, 5.0 / 3.0, -9.0 / 8.0, 15.0 / 8.0, "-(9/8)x + 15/8")));
}
```

Evaluación, ubicando primero a qué tramo pertenece `x`:

```java
public double evaluar(double x) {
    int indice = indiceDeTramo(x);
    return indice < 0 ? 0.0 : tramos.get(indice).evaluar(x);
}

public int indiceDeTramo(double x) {
    for (int i = 0; i < tramos.size(); i++) {
        Tramo t = tramos.get(i);
        boolean dentro = (i == 0)
                ? (x >= t.inicio() && x <= t.fin())
                : (x > t.inicio() && x <= t.fin());
        if (dentro) {
            return i;
        }
    }
    return -1;
}
```

Convención: el primer tramo incluye sus dos extremos; los siguientes excluyen
el izquierdo. Así un valor justo en la frontera (p. ej. `x = 1`) siempre cae
en el tramo anterior, tal como exige la prueba de escritorio.

También calcula la constructora `M` a partir del máximo de todos los tramos,
y la eficiencia teórica del método:

```java
public double eficienciaTeorica() {
    return 1.0 / (maximo * (limiteSuperior - limiteInferior));
}
```

## `SimuladorRechazo`

El algoritmo en sí. Constructor recibe la densidad y la fuente aleatoria;
`simular(...)` ejecuta el número de iteraciones pedido.

```java
public ResultadoRechazo simular(int iteraciones, ProgresoSimulacion.Monitor monitor) {
    double a = densidad.limiteInferior();
    double b = densidad.limiteSuperior();
    double m = densidad.maximo();
    ...
    for (int i = 1; i <= iteraciones; i++) {
        double r1 = fuente.siguiente();
        double r2 = fuente.siguiente();
        double x = a + (b - a) * r1;          // ubica x en [a, b]
        double fx = densidad.evaluar(x);
        double razon = fx / m;                 // f(x) / M
        boolean aceptado = r2 <= razon;        // criterio de aceptación

        if (aceptado) {
            aceptados++;
            sumaAceptados += x;
            conteos[claseDe(x, a, b)]++;        // acumula histograma
        }
        traza.add(new IteracionRechazo(i, r1, r2, x, indiceTramo, fx, razon, aceptado));
    }
    ...
    return new ResultadoRechazo(densidad, iteraciones, traza, ...,
            aceptados, rechazados, tasa, densidad.eficienciaTeorica(), ...);
}
```

Por cada iteración: `R1` ubica el punto `x` dentro de `[a, b]`; `R2` decide si
se acepta comparándolo contra `f(x)/M`. El método acumula en paralelo la
traza (para la prueba de escritorio), el histograma de aceptados y la tasa de
aceptación observada, que debe acercarse a la tasa teórica `1/(M·(b−a))`.

## `IteracionRechazo` y `ResultadoRechazo`

Dos records de datos, sin lógica de negocio, que alimentan directamente las
tablas y gráficas del informe.

```java
public record IteracionRechazo(
        int numero, double r1, double r2, double x,
        int indiceTramo, double fx, double razon, boolean aceptado) { ... }

public record ResultadoRechazo(
        DensidadPorTramos densidad, int iteraciones, List<IteracionRechazo> traza,
        boolean trazaTruncada, int aceptados, int rechazados,
        double tasaAceptacion, double tasaTeorica,
        double[] bordesHistograma, int[] conteosHistograma, double mediaAceptados) { ... }
```

- `IteracionRechazo` = una fila de la prueba de escritorio (`i, R1, R2, x, tramo, f(x), f(x)/M, aceptado/rechazado`).
- `ResultadoRechazo` = el resumen final: cuántos se aceptaron, tasa observada
  vs. teórica, e histograma de `x` aceptados para comparar contra `f(x)`.
